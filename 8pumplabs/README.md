## ✨ About

**Web3 Marketing Agency** is a commercial landing page built for a real client in the blockchain space.  
The project focuses on community growth, KOL partnerships, and promotion of Web3 products.

It was used in production for client acquisition and marketing purposes, and remained active for a period of time.

---

## ⚡ Highlights

- Responsive layout across all devices
- Parallax hero section with layered typography
- Animated counters for key business metrics
- Scroll-based animations (Intersection Observer)
- Infinite horizontal partners/projects slider
- Structured services, team, and projects sections
- Conversion-focused layout with multiple CTA blocks
- Optimized performance (PageSpeed 90+)
