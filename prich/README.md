---

## ✨ About

---

**PRICH** is a promotional landing page for a meme token project built around a bold “rich mindset” concept, combining humor, AI-driven content, and strong visual identity.

The website delivers a dynamic Web3 experience with a focus on storytelling, token presentation, and user engagement. It guides users through the ecosystem, from introduction and tokenomics to AI-powered social presence and merch integration.

The design emphasizes motion, layered visuals, and interactive components, creating an immersive and conversion-oriented interface.

---

## 🚀 Features

---

- 🎨 Custom UI/UX with strong meme-driven branding
- 📱 Fully responsive layout
- ⚡ Optimized performance (lazy loading, efficient assets)
- 🎞️ Scroll-based animations (watcher system)
- 🧠 Intersection Observer-based appearance triggers
- 🌀 Smooth navigation with anchor scrolling
- 💰 Tokenomics table with structured data
- 📋 Copy-to-clipboard (contract address)
- 💸 “How to Buy” step-by-step section
- 🤖 AI-powered content block (Twitter/X integration concept)
- 🧾 Social-style cards with dynamic layout
- 🛍️ Merch slider (Swiper) with product showcase
- 🎯 Interactive UI elements with staged animations
- 🔗 Social links integration (X, Telegram, DEX)
