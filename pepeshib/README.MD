# 🐸 PESHI Landing Page

💼 **Commercial Project**

🔗 Live Demo: https://nimble-parfait-368b96.netlify.app/

---

## ✨ About

**PESHI** is a promotional landing page for a meme token project built around a unique character inspired by crypto culture.

The website presents the project’s story, showcases NFT collections, promotes merch, and provides a clear step-by-step guide on how to buy the token.

The design focuses on a bold, animated experience with strong visual identity, combining storytelling and interactive elements for Web3 engagement.

---

## 🚀 Features

- 🎨 Custom UI/UX with strong branding
- 📱 Fully responsive layout (mobile-first)
- ⚡ High performance (PageSpeed 90+)
- 🎞️ Rich animations and scroll-driven effects
- 🎯 Scroll-based navigation (watcher system)
- 🖼️ NFT & merch sliders (Swiper.js)
- 🎬 Interactive media section (video/story)
- 💰 “How to Buy” step-by-step guide
- 🔗 Web3 integrations (NFT platforms, wallets)
- 📋 Copy-to-clipboard (contract address)
- ❓ FAQ with accessible accordions

---

## 🛠️ Technologies Used

- HTML5

- JavaScript (ES6+)
- Gulp
