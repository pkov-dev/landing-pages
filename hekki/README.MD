# 🦔 Hekki Landing Page

💼 **Commercial / Promo Project**

🔗 Live Demo: https://loquacious-genie-c0587e.netlify.app/

---

## ✨ About

**Hekki** is a promotional landing page for a meme token built on the Solana blockchain.  
The project is centered around a playful spiky mascot and aims to attract users through strong visuals, community-driven messaging, and a simple onboarding experience.

The website introduces the token, explains how to buy it, and presents its roadmap and tokenomics in an engaging way.

---

## ⚡ Highlights

- Eye-catching hero section with character-focused design
- Fully responsive layout across all devices
- Scroll-based animations (Intersection Observer)
- Structured sections: About, Roadmap, How to Buy, Tokenomics
- Clear CTA blocks for conversion (Buy / Chart)
- Social integrations (X, Telegram)
- Copy-to-clipboard contract address feature
- Optimized performance (PageSpeed 90+)
