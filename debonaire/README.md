# ✂️ Debonaire Landing Page

🔗 Live Demo: https://earnest-meerkat-0a46a7.netlify.app

---

## ✨ About

**Debonaire** is a modern landing page for a hair design and boutique studio.

The project focuses on visual storytelling, showcasing services, brand identity, and creating a premium user experience through smooth interactions and layout flow.

---

## ⚡ Highlights

- Fully responsive layout (desktop / tablet / mobile)
- Parallax effects across multiple sections (mouse & scroll-based)
- Layered hero section with depth and motion
- Scroll-triggered animations and element reveals
- Rich visual composition with images and SVG decorations
- Smooth section transitions and layout flow
- Service showcase with interactive presentation
- Optimized assets and performance

---

## 🛠 Tech Stack

- HTML
- SCSS
- JavaScript
- Gulp
- Webpack
- Parallax system (data-attribute driven)
- Intersection Observer API
