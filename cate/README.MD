# 🐱 CATE Landing Page

💼 **Commercial Project**

🔗 Live Demo: https://meek-kangaroo-099123.netlify.app/

---

## ✨ About

**CATE** is a promotional landing page for a meme token project inspired by playful crypto culture and character-driven branding.

The website introduces the project concept, highlights key benefits, presents tokenomics, and provides a clear step-by-step guide on how to buy the token.

The design focuses on a clean, engaging visual style with smooth interactions and strong emphasis on usability and storytelling.

---

## 🚀 Features

- 🎨 Custom UI/UX with strong visual identity
- 📱 Fully responsive layout (mobile-first)
- ⚡ High performance (PageSpeed optimized)
- 🌀 Smooth scrolling powered by Lenis
- 🎞️ Scroll-based appearance animations (watcher system)
- 💰 Step-by-step “How to Buy” guide
- 🗺️ Roadmap section
- 📊 Tokenomics presentation
- 📋 Copy-to-clipboard functionality (contract address)
- 🔗 Social & Web3 integrations

---

## 🛠️ Technologies Used

- HTML5
- SCSS (Sass)
- JavaScript (ES6+)
- Gulp
- Swiper.js
- Lenis (smooth scrolling)
