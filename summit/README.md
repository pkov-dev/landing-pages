# 🚀 Crypto Event Landing Page

💼 **Commercial / Promo Project**

🔗 Live Demo: https://sage-narwhal-b2eb12.netlify.app/

---

## ✨ About

**Crypto Event Landing** is a promotional landing page for a Web3 & memecoin-focused event in Singapore.
It presents key event details, highlights, partners, and provides a simple registration flow.

---

## ⚡ Highlights

- Eye-catching visuals with themed sections and animations
- Fully responsive layout across all devices
- Scroll-based animations (Intersection Observer)
- Structured sections: Why Attend, Event, Partners, Location, FAQ, Registration
- Interactive counters (partners, speakers, sessions, seats)
- Marquee sliders for partner logos
- Embedded Google Maps location
- Accordion-based FAQ system
- Registration form with validation and file upload
- Telegram form integration with loading state
- Social integrations (X, Telegram, Instagram)
