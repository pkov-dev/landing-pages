# 🐸 NEARKAT Landing Page

💼 **Commercial Project**

🔗 Live Demo: https://fanciful-sunflower-24ef33.netlify.app/

---

## ✨ About

**NEARKAT** is a Web3 landing page for a meme token on the NEAR Protocol, built around the NearKat mascot concept.

It combines storytelling, token presentation, and a clear user flow from introduction to purchase.

---

## ⚡ Highlights

- Fully responsive layout (desktop / tablet / mobile)
- Scroll-triggered animations using modern CSS Scroll-Driven Animations API
- Intersection Observer-based reveal system
- Parallax effects in NFT section (mouse-driven layered motion)
- Custom SVG animations (decorative and roadmap elements)
- Smooth navigation between sections (scroll navigation system)
- Interactive UI components (FAQ accordion, copy-to-clipboard contract)
- Optimized media loading (lazy images, decoded assets)
- High-performance build (PageSpeed ~100)
