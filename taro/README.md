# 🐕 Maru Taro Landing Page

💼 **Commercial / Promo Project**

🔗 Live Demo: https://creative-sunshine-b7c57d.netlify.app/

---

## ✨ About

**Maru Taro** is a promotional landing page for a meme token on the Solana blockchain, inspired by the legendary Shiba Inu.

The project focuses on fun, emotional storytelling, and strong visual identity to build a community-driven crypto brand.  
It combines playful design, smooth animations, and a simple onboarding flow for new users.

---

## ⚡ Highlights

- Character-driven hero section with strong visual identity
- Smooth scrolling powered by Lenis
- Fully responsive layout across all devices
- Scroll-based animations (Intersection Observer)
- Animated storytelling sections (Legend block)
- Infinite marquee text (community takeover message)
- Structured sections: About, Legend, How to Buy, Tokenomics
- Clear CTA blocks (Buy Now)
- Social integrations (X, Telegram, Instagram)
- Copy-to-clipboard contract address feature
- Optimized performance (PageSpeed 90+)
