# 🧩 Minimal Multipurpose Landing

💼 **Practice / Concept Project**

🔗 Live Demo: https://tourmaline-tanuki-fcfb07.netlify.app

---

## ✨ About

**Minimal Multipurpose Landing** is a full-page scrolling website built with a focus on simplicity, structure, and clean visual presentation.

The project showcases a modular layout with multiple sections, combining content blocks, statistics, and visual elements into a smooth vertical experience.

---

## ⚡ Highlights

- Full-page scrolling layout (section-based navigation)
- Smooth transitions between screens
- Structured modular sections (content, services, projects, stats)
- Animated counters for statistics
- Clean minimal UI with strong typography
- Responsive layout across all devices
- Balanced composition of text and imagery
- Optimized performance and smooth rendering

---

## 🛠 Tech Stack

- HTML
- SCSS
- JavaScript
- Gulp
- Webpack
- Full-page scroll system (section-based navigation)
- Intersection Observer API
