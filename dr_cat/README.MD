# 🐾 Dr. Cat

🔗 Live Demo: https://clinquant-sopapillas-8d48c7.netlify.app/

## ✨ About the Project

**Dr. Cat** is a promotional landing page for a crypto token built on the Base network.  
The project combines a playful meme-style concept with a structured presentation of tokenomics, onboarding steps, and community-driven goals.

---

## 🚀 Features

- Responsive and modern UI
- Smooth animations and interactive elements
- Step-by-step guide for purchasing the token
- Tokenomics section
- FAQ block for user onboarding
