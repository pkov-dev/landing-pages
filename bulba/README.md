💼 **Commercial Project**

---

## ✨ About

**Bulbaseor** is a promotional landing page for a meme token project on Base, built around a playful monster-catching visual theme.
The website is designed to introduce the character and token, explain how to buy, present tokenomics, and guide users toward community and trading links.

The project combines custom illustrated sections, scroll-triggered animations, and conversion-focused CTA blocks in a single responsive landing page.

---

## ⚡ Highlights

- Responsive landing page for desktop and mobile devices
- Large hero section with layered decorative artwork
- Themed art direction inspired by collectible creature / battle-card visuals
- Step-by-step "How to Buy" section for onboarding users
- Roadmap section with three project phases
- Tokenomics block with supply, tax, LP status, and copy-to-clipboard contract address
- Scroll watcher animations and smooth in-page navigation
- Social and trading links integration for community growth
